# CLAUDE.md — Capacity Atlas Lite

Project memory for Claude Code. Read this first.

## What this is
A **growth-stage** capacity + staffing + compensation workbook — the simple version of the Capacity Atlas for a business not yet ready for the full web tool. Built for a tax-resolution firm (David J Griggs, CPA) but the structure fits any caseload-based service business. Delivered as **`Capacity-Lite.xlsx`** — live Excel formulas, no code to run.

The full web Atlases are siblings: `capacity-atlas-product` and `capacity-atlas-service`.

## The workbook (6 tabs, all cross-linked)
1. **Capacity Lite** — revenue-based capacity. Source of truth for the drivers.
2. **Org & Hiring** — four hiring triggers (case managers, admins, AEs, case directors).
3. **Profitability** — old vs new comp model, annual run-rate P&L.
4. **James — New Comp** — change-management chart (his pay old vs new).
5. **Cash Timing** — commission paid up front vs fees collected over time.
6. **Comp Optimizer** — highest affordable commission rate.

`Capacity Lite` feeds the rest; changing a driver there flows through every tab.

## The model (do not break these invariants)
- **Capacity is a REVENUE ceiling per worker; case counts are DERIVED**, not the primary driver. (This was an explicit pivot — see HISTORY.)
- **Binding capacity = MIN(calculated, operational).** Calculated = revenue ceiling ÷ case value (~143). Operational = the owner's real estimate of cases a manager can carry (~90). The lower one binds and drives everything. A flag fires when the base price can't reach the revenue target at the operational caseload.
- **Admins are a capacity multiplier**, not just overhead: they lift cases-per-manager from ~90 toward ~130. The "humans vs admins" trade-off is a first-class lever.
- Verdict language: **SELL MORE / MAINTAIN / ADD CAPACITY**.

## Conventions
- Cell colours: 🟡 yellow = user data · 🔵 blue = model definitions · 🟠 gold = key results.
- Everything is a **live formula** — never hard-code a value a formula should produce.
- The file is generated by an `openpyxl` Python script during development; if regenerating, keep cross-sheet references intact (many tabs link to `'Capacity Lite'!` cells by exact address).
- Comp/overhead numbers are **placeholders** pending the owner's actuals.
